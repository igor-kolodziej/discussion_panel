## Common Fatal Pattern

The physical-control ideas are better than generic workflow ideas, but simulated reviewers still cap them when:

- the first niche looks too small for a domination-oriented company;
- average order value is low;
- incumbent local operators already own trust and could copy the visible workflow;
- the control point is physical stock but not strategic enough to expand asymmetrically.

## Next Direction

Test regulation-timed or forced-flow physical systems where local placement and transaction data can compound beyond a parts bank:

- deposit-return backroom control for small stores;
- pharmacy/clinic shortage routing if legally narrow enough;
- discharge equipment home-readiness where referral flow and fitted inventory matter;
- other ideas where a first controlled node can become citywide infrastructure.
