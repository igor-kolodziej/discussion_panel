# Zero-to-One Pivot: Haptic Accessibility Module OEM

## Preserved Insight

Industrial event semantics and a validated haptic vocabulary can make an adapted workcell usable for a deaf employee.

## Structural Change

Change the buyer from the employer/end workcell to the small Polish PLC integrator already holding the employer's machine-access and maintenance relationship. Sell a prepaid white-label hardware/software module and validation kit the integrator can include in an awarded PFRON/employer adaptation, rather than competing for site integration.

## Target Niche and Buyer

Polish PLC/HMI integrators with 10–50 staff and at least one live accessibility/adaptation request but no reusable haptic module. Buyer: owner or engineering manager after winning/quoting an adapted workcell.

## Painful Event and Willingness to Pay

The integrator needs to quote and deliver an unfamiliar accessibility requirement without building wearable firmware, haptic tests, and documentation from scratch. Hypothesis: it prepays 12,000–20,000 PLN for a module kit and pays 3,000–6,000 PLN annual licensing plus per-cell devices.

## Value and Profit Wedge

White-label gateway firmware, COTS-band interface, five-event ontology, worker comprehension test, documentation templates, and remote configuration. The integrator owns cell wiring/site relationship; the company owns module/software/protocol and charges per deployed cell.

## Domination Wedge

Become the default accessibility module for small integrators serving PFRON-funded workcells, with machine-family adapters and documentation shared across resellers.

## Acquisition Channel

Direct event-based outreach to FAIRP/integrator directories and public adaptation/funding content. Sell only against a named project; no speculative reseller partnership.

## Primary Control Point

Owned module firmware, licensing keys, protocol, documentation, haptic test, and cross-integrator adapter library. Per-cell licenses contractually route deployments through the company.

## Cold Start and Resource Bootstrap

Build bench kit under 20,000 PLN. Require one integrator's prepaid named-project order before custom PLC adapters. Proof within 12 months is two integrators, three licensed cells, and one reused adapter.

## Expansion Path

Additional integrators, ordinary/noisy workcells, and EU distributors. Safety-rated products remain excluded.

## Minimum People Stack

Founder, embedded/PLC contractor, accessibility tester, legal/product-liability review.

## Principal Risk

Integrators rarely see enough accessibility projects to buy, can build the simple module themselves, demand white-label ownership, or refuse per-cell fees. The new channel may be a speculative partnership in disguise.

## First Disconfirming Test

From 50 integrators, obtain one prepaid named-project module order within 180 days. Kill if nobody has a live adaptation, wants only free exploratory support, or demands all IP/work-for-hire.

## Evidence Preserved

PFRON budget, public integrator/employer discovery, technical feasibility, and the panel's consensus that integrator trust/access dominates direct sales.

## New Hypotheses

Integrators encounter enough requests; 12,000+ PLN prepaid WTP; per-cell license acceptance; module is difficult enough not to build internally; named projects appear within 180 days; integrators allow the company to retain generic adapters.

## Why This Is Not the Original Failure Shape

The incumbent integrator becomes the buyer/channel rather than the copy threat. Value capture shifts from site service/support to licensed module/per-cell deployment. It remains invalid if access depends on speculative reseller enthusiasm rather than a prepaid named project.

## Priority

This is the only structural pivot that directly accepts the panel's channel objection. It should be killed if named accessibility project frequency cannot support a licensed module company.
