# Simulated Zero To One Scores - Round 3

## Scores

- R3-A DentX-Ray Compliance Calendar Buyout: **66/100**. Control point tier: contractual distribution/customer book. Main objections: accredited lab captures margin, weak defensibility, clinic book transfer risk.
- R3-B CleanBench Validation Route Buyout: **74/100**. Control point tier: acquired recurring route. Main objections: technician dependency, route may be a job not a company, procurement/vendor qualification friction.
- R3-C RetainRelease Public Contract Security Recovery Rail: **68/100**. Control point tier: moderate operational control. Main objections: case-size ambiguity, legal/trust boundary, episodic retention, copy by law/accounting firms.
- R3-D UDTLift/Forklift Service Calendar Buyout: **72/100**. Control point tier: fragile route-control. Main objections: technician dependency, field-service fit, local incumbent copy, acquisition transfer risk.
- R3-E FoodMetal Detector Validation Route Buyout: **72/100**. Control point tier: operational workflow control. Main objections: technician dependency, OEM/service provider copy, audit-document acceptance, part-time ops burden.
- R3-F Local Exhaust / BHP Measurement Route Buyout: **74/100**. Control point tier: useful route-control. Main objections: subcontractor disintermediation, commoditization, book quality, margin leakage.

## Decision

Round 3 produced credible acquisition-backed boring businesses, but none cleared the simulated `>85` gate. Their control points are real but fragile: customer calendars can transfer poorly, technicians/subcontractors can disintermediate, and incumbents can copy managed-renewal workflows. Round 4 must combine acquired or routed demand with a more durable, compounding asset: scarce credentialed capacity, locked transaction flow, or hard-to-recreate public/private data rights.
