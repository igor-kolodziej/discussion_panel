## Diagnosis incorporating both panels

Both independent judges found the same fatal commercial objection: the customer gives up 86,400 PLN across five years for an approximately 15,000 PLN asset that incumbents market with 6–12-month payback, and an established vendor can copy the electrician annuity with one routine offer. This is not a parameter problem. Reducing the term/share destroys the portfolio margin and finance thesis; keeping it destroys customer value. The upstream installer pivot therefore did not escape the same buyer and trust mechanism.

Both also exposed errors/omissions: target gross margin is 61.1% after straight-line depreciation, not 65%; the conservative founder value used enterprise value as equity without deducting 7.5m PLN asset debt; charge incidence and independent-originator throughput are unproved.

## Gates and control

- Founder Wealth Gate: **fail as written**. Correct conservative equity can be about 4.61m PLN if the full facility remains outstanding.
- Reachability Gate: **pass**, but it cannot compensate for wealth/control/customer-value failure.
- Control point: Tier 1 per site, not a portfolio acquisition moat.
- Strongest copy risk: established ESCO/vendor adds the referral share and underprices the founder using cheaper capital/trust.

## Recommendation

**kill the entire reactive-power savings/financed-cabinet shape.** Do not reduce the percentage, shorten the contract, add dashboard features or rename the installer network. Two judges identified the same fatal objection, and the copy mechanism is structural. Return to `generate-zero-to-one-candidates` in the same run folder with this rejection recorded.
