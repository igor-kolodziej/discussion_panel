## Current Lead

**FaultBox Lithium Return Crate Rights** is the only Round 3 candidate that appears capable of crossing the simulated `>85` gate because it combines:

- current regulatory and insurer/fire-pressure momentum;
- physical deployed resource control rather than advice;
- buyer-paid retainer before inventory purchase;
- cold-startable direct acquisition;
- repeatable site-level default workflow;
- credible under-100,000 PLN proof without the founder acting as an unlicensed waste operator.

The idea must be killed if licensed collector/ADR partner acceptance cannot be signed, or if sellers will not prepay crates.
