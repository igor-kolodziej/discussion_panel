# Zero-to-One Pivot: AgencyRail Transaction Plugin Buyout

## Preserved Insight

The valuable asset is the installed update/payment rail and workflow history, not source code.

## Structural Change

Stop acquiring ordinary annual-licence plugins and stop relying on 60,000 direct site subscriptions. Acquire only a WooCommerce plugin that already routes a paid operational transaction—shipping label, returns pickup, warranty service, trade-in, or fulfilment order—and already earns a per-transaction fee or assigned commission from its installed merchants. The buyer model changes from renewal licences to a take rate on existing merchant transaction flow.

## Target Niche and Buyer

One narrow post-purchase workflow used by small WooCommerce merchants, where the plugin currently routes at least 2,000 paid third-party transactions per month and the merchant saves time or carrier/vendor cost. The paying economic customer is the merchant/vendor on each routed transaction.

## Painful Event and Willingness to Pay

Every fulfilment, return, warranty or trade-in event requires execution; the current fee history proves willingness. Switching means reconfiguring operations and vendor accounts.

## Value and Profit Wedge

Buy the official update channel, installed merchants, transaction ledger, payout contracts, licence server, code/IP, and assigned vendor economics. Keep the existing per-transaction fee and improve routing/volume before selling subscriptions. Acquire for <=28,000 PLN cash plus a seller note payable only from existing transaction receipts.

## Domination Wedge

Dominate one post-purchase event for a narrow merchant segment through installed routing and vendor/merchant history. The control point is stronger than licences because it touches recurring transaction flow.

## Acquisition Channel

Search plugin marketplaces, WordPress retirement signals, small shipping/returns tools, and direct developer outreach. Require processor/vendor statements and contract assignment before an LOI.

## Primary Control Point

Atomic transfer of official update authority, installed merchants, transaction-routing configuration/history, billing/payout rights, assignable vendor contracts, licence server, domain/brand, and complete IP. If vendor economics or payout contracts do not transfer, the deal is Tier 3 and dies.

## Cold Start and Resource Bootstrap

Screen 150 targets, obtain five transaction data rooms, sign one escrowed deal, and receive the first routed commission within 180 days and 40,000 PLN. No new vendor partnership is allowed; every vendor relationship must already exist and be assignable.

## Expansion Path

Grow transaction volume inside the acquired installed base, then acquire adjacent event-routing plugins sharing merchants/vendors. Founder wealth comes from GMV/take rate rather than tens of thousands of annual licences.

## Minimum People Stack

Founder, WordPress/security engineer, transaction lawyer, and support contractor after receipts.

## Principal Risk

The target set may be empty inside the capital limit because a plugin with transferable, profitable transaction flow is already valuable. Vendor contracts may be non-assignable or allow disintermediation.

## First Disconfirming Test

Within 60 days, identify three targets with primary statements proving at least 2,000 monthly transactions and assignable payout/vendor contracts. Kill if none accepts a <=28,000 PLN cash plus receipts-note structure.

## Evidence Preserved

Official update transfers and installed workflows remain real; the v1 panel confirms the first-asset control and reachability.

## New Hypotheses

An affordable transaction-routing target exists; vendor/processor contracts assign; take-rate margins survive transfer; GMV can scale through the installed base without new privileged partnerships.

## Why This Is Not the Original Failure Shape

V1 required 60,000 direct paying sites. AgencyRail changes value capture to a per-event take rate on already flowing transactions and requires transferred vendor/payment contracts, allowing fewer merchants and larger revenue per installed workflow. If those contracts are not already operating and assignable, the pivot is killed rather than reverting to subscription roll-up.

## Priority

Return AgencyRail to the evaluator first because it directly replaces the heroic customer-count bridge with controlled transaction flow.
