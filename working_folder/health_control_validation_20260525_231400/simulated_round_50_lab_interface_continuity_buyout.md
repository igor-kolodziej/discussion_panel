## Materially Narrowed Candidate

`Lab Interface Continuity Buyout`

This candidate buys or options tiny Polish lab-interface MSP/vendor maintenance books that already bill private molecular, IVF, pathology, and diagnostic labs for live LIS/LIMS, HL7/ASTM, instrument, billing, and result-delivery integrations.

It does not acquire patient books, run a lab, interpret test results, sell tests, build new integrations during the proof, or operate a diagnostic/medical-device software product.

## Control Point

The control point is the acquired production workflow plus payment/admin custody:

- existing maintenance invoices or renewal rights;
- source code, mappings, runbooks, test files, deployment notes, and known edge cases;
- support mailbox and ticket history;
- customer-approved admin transfer;
- processor terms / DPAs where applicable;
- deployment/update credentials and release paths;
- one retiring or overloaded seller's signed handoff;
- five lab customers signing continuity contracts and prepaying three months before close.

## Two-Month Proof

Required before meaningful closing payment:

1. One signed acquisition/option agreement with a retiring or overloaded micro-vendor.
2. Clean IP/assignment/DPA review.
3. Five lab customers approve admin transfer and sign new/novated continuity contracts.
4. At least `25,000 PLN` prepaid three-month support/transition cash clears before close.
5. Credentials are rotated, access logs established, and backup/rollback procedure documented.
6. One live interface ticket is resolved under the new owner.
7. Support history shows mostly reusable maintenance, not bespoke lab IT chaos.
8. All clinical interpretation, diagnostic logic, result modification, QC interpretation, and medical/IVD software functionality are excluded.

- Smaller and more concrete buyer set.

- Any patient/health/genetic data access requires proper processor terms, least privilege, logs, breach process, and data minimization.

- If the interface changes clinical meaning or device output, it must be carved out.
- Liability caps and professional/cyber insurance need legal review before live operation.
