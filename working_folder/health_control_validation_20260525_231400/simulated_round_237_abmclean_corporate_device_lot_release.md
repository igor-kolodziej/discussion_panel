## Internal Objections Before Real Gate

- ITAD providers, MSPs, Apple consultants, and refurbishers are natural incumbents.
- Activation Lock and MDM release have scam-adjacent optics; source-company title/admin proof must be non-negotiable.
- If companies already use competent ITAD providers, the startup is unnecessary.
- Device data erasure and asset-disposal handling require strict chain-of-custody, audit logs, and contractors.
- Apple/MDM release sequencing can be operationally brittle.
- Buyer deposits may depend on inspection, grade, battery/cosmetic condition, and successful release.
- One lot is a transaction, not a company; repeat source channels through MSPs/accountants/refurbishers must compound.
