2. The release sequence is sensitive: Activation Lock may need to be turned off before organization release, then devices must be erased, restored, and verified.
3. Many devices are unrecoverable or unsafe: consumer iCloud locks, lost/stolen devices, financed devices, blacklisted IMEIs, unclear title, missing admin route, or old bypass codes.
4. The founder will face trust stigma because the category sits next to gray-market unlocking.
5. The 60-day proof is aggressive without warm ITAD relationships and very clean lots.
6. ITADs, MSPs, Apple-focused consultants, and refurbishers may already solve the cleanest cases.
7. Success-fee attribution can be disputed if a buyer or original owner already had a release path.
8. Buyers may push the founder into erasure, testing, grading, resale, warranty, or broader ITAD operations.
9. Apple support cannot be assumed for bulk third-party resale cases; the reliable path is original owner/admin action.
10. Signed batch control protects current serials, but the broader moat is not deep.

## Useful Narrowing

The evaluator said the best first version would be **corporate Apple lot release recovery for ITAD/refurbishers with clean title and reachable original-owner admin routes**.

Start only with:

- ABM/ASM devices still assigned to an organization;
- organization-linked Activation Lock where the organization can act;
- supervised devices where MDM/admin routes exist;
- recent corporate refresh or lease-return lots with documented seller contacts.

Avoid:

- consumer iCloud locks;
- random auction lots;
- phones with lost/stolen/blacklist risk;
- old school or enterprise lots with no living admin route;
- any bypass, firmware, or gray-market work.

Suggested POC correction:

- 500-1,500 serials screened;
- 100-300 devices released or verified clean;
- 40,000-150,000 PLN in fees;
- at least one repeatable release route.
