Product wedge:
TraceFaktura is a mobile-first event-stamping rail, not a dashboard. Contractor field staff, dispatchers, shelter staff, or cooperating vets capture each billable animal event through a very lightweight WhatsApp/QR/mobile web flow: animal ID or provisional ID, date/time, GPS or location, photo/video, chip/tag if available, service type, vet/shelter counterparty, required consent/receipt/protocol fields, and responsible person.
