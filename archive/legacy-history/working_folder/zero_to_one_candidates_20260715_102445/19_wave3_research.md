# Wave 3 Research

Sources retrieved 2026-07-15.

## HoloLens Uptime & Exit Rail

- Microsoft states HoloLens 2 is no longer manufactured and is out of stock in all geographies. [Microsoft Learn](https://learn.microsoft.com/en-sg/hololens/hololens2-purchase)
- Microsoft states the current release is the final feature release and security servicing continues through December 2027. [HoloLens release notes](https://learn.microsoft.com/da-dk/HoloLens/hololens-release-notes)
- Microsoft published a 2024 Mixed Reality Partner Program member list, providing a public acquisition source, not a customer denominator. [MRPP list](https://www.microsoft.com/content/dam/microsoft/final/en-us/microsoft-product-and-services/hololens/MRPP%20Member%20Tier%20List%20Feb%202024.pdf)
- Microsoft documents enterprise deployments and fleet management, showing critical-use cases but not current active fleet counts. [Microsoft industrial HoloLens case](https://news.microsoft.com/source/features/innovation/hololens-2-industrial-metaverse/)
- Hypotheses: used/testable devices can be acquired below 6,000 PLN each; 80 EU sites will pay 120,000 PLN annually for uptime/migration; an unknown founder can pass enterprise security/procurement in 180 days.

## SpeechBridge Workline

- Voiceitt already provides speech recognition for non-standard speech, validating need and powerful incumbent substitution. [Voiceitt](https://voiceitt.com/)
- Google reports Project Relate was built with more than one million speech samples, demonstrating the data and model difficulty. [Google Project Relate](https://blog.google/company-news/outreach-and-initiatives/accessibility/project-relate/)
- Apple offers on-device Personal Voice, creating free platform substitution for synthetic voice output but not necessarily two-way work-call reliability. [Apple Personal Voice](https://support.apple.com/en-lamr/104993)
- Hypotheses: five professionals prepay 900 PLN; a browser/softphone plus human fallback delivers important calls; 4,000 global subscribers at 249 PLN/month are reachable with acceptable support/CAC; personalised history creates retention despite incumbent features.
