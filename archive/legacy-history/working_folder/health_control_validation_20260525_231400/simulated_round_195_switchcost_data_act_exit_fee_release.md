## Why It Clears The Simulated Gate

- The commercial trigger is live: a migration, renewal, acquisition, customer commitment, or cost-reduction project is stuck because a provider has quoted export/switching fees, delayed data release, or imposed questionable migration-support charges.
- The proof artifact is current money or data movement: reduced/withdrawn switching charge, provider-accepted export plan, actual export delivery, credit note, or paid clean no-go.
- The legal boundary can be controlled by using counsel only for legal interpretation and selling operational charge/evidence reconstruction.
- It is materially different from the confirmed Data Act machine-data desk: the buyer, chapter, event, artifact, and economics are cloud/data-processing switching, not connected-product industrial telemetry.

## Internal Caps Applied

- Cap below 82 if there is no live provider quote/invoice/ticket and migration deadline.
- Cap below 85 if the startup sells generic Data Act advice, contract review, cloud migration, or FinOps.
- Cap below 87 if counsel/cloud MSP partners own the case and the founder controls only a memo.
- Cap below 87 if reductions are not confirmed by provider credit, revised invoice, export delivery, or customer migration progress.

## Main Risk Before Real Validation

The evaluator may see this as Data Act legal/cloud consulting where law firms, MSPs, cloud FinOps firms, migration consultants, and provider account teams already own the workflow. It should advance only if the live charge/export-release mandate is treated as hard current-cash control.
