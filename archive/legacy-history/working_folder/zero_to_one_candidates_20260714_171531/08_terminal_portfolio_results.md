## Reusable conclusions for a future run

1. Owning a prototype, CAD, firmware or a future dataset is not a first-order control point when an incumbent already owns the buyer's trusted workflow and channel.
2. Consumer wearable wealth cases need a bottom-up bridge from first 100 to expected annual volume, including VAT, compliance, support, returns, working capital and channel throughput.
3. Preorders are valid pre-implementation paid proof of interest, but the first deliverable batch must fit the same staged-capital logic without circular dependence on post-delivery economics.
4. A future search should favor control acquired independently of the customer—exclusive rights, scarce inventory with verified demand, a legally mandatory transaction route, or patented/protected core physics—where a non-heroic expected wealth case can be sized before product engineering.
