# Health-Focused Candidate Matrix

Context constraints:

- Domains allowed: elderly people, genetics, EEG.
- Founder: Warsaw data scientist, neuroscience/EEG background, 100,000 PLN max, part-time, low-camera, low-status-networking.
- Must secure or prove a concrete control point in 2 months.
- Avoid existing ideas: biosignal investor diligence, supplement/lab passport, generic health reports, generic dashboards, evidence packs already covered.
