# Simulated Zero To One Scores - Round 1

## Scores

- F1 ChromatoSwap HPLC Uptime Pool: **68/100**. Control point tier: operational/local control point. Main objections: technician trust, inventory mismatch, qualification paperwork, underpriced SLA risk, existing technicians/dealers can copy.
- F2 PLC Ghost Stock: **72/100**. Control point tier: strong local operational control, not structural monopoly. Main objections: first contractor can copy, inventory breadth, program-backup access, warranty liability.
- F3 ImplantKey Orphan Components Bank: **58/100**. Control point tier: moderate physical/control-data point. Main objections: medical-device regulatory trap, traceability, trust, irregular demand.
- F4 LiftBoard Emergency Pool: **59/100**. Control point tier: moderate operational control. Main objections: rare-event demand, elevator safety trust/liability, working-capital drag, copy by incumbents.
- F5 StabilityChamber Overflow Options: **54/100**. Control point tier: soft contractual control. Main objections: incumbent labs already offer backup/overflow, trust-heavy, supplier-dependent, weak founder fit.
- F6 Dissolution Tester Uptime Pool: **64/100**. Control point tier: niche operational control. Main objections: small installed base, rare failures, slow pharma procurement, technician/reseller copy risk.

## Decision

No candidate passed the simulated `>85` gate. The equipment-continuity cluster is commercially real but structurally too dependent on technician trust, partner channels, and inventory breadth. Pivot away from service-like uptime pools toward businesses where the founder can secure an upstream scarce resource, paid option, rights, or transaction flow within 12 months and under 100,000 PLN.
