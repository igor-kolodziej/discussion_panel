# Document Request

## Objective
Create the minimum viable document request for one retailer/channel audit.

## Prerequisites
- Audit scope is defined.
- Brand has agreed to a call, NDA-backed pilot, or paid audit.
- The first audit must stay narrow.

## Inputs
- Audit scope memo.
- Retailer/channel selected for the pilot.
- Discovery-call notes if available.

## Instructions
1. List must-have documents.
2. List useful optional documents.
3. Define the minimum data packet if the brand wants to start with redacted files.
4. Give simple instructions for file naming and date range.
5. Ask only for what is needed to test leakage.

## Subagents
- Use one subagent to critique whether the request is too heavy for a first pilot.
- Use one subagent only if a specific retailer/channel requires special document types.

## Output
Return:
- must-have document list
- optional document list
- minimum redacted data packet
- file naming instructions
- short email to send the request
