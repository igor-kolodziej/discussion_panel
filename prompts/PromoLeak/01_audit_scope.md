# Audit Scope

## Objective
Define the first PromoLeak audit so it is narrow enough to sell, execute, and judge quickly: one brand, one retailer/channel, 6-12 months of documents, and one clear leakage metric.

## Prerequisites
- PromoLeak idea file has been read: `ideas/CONFIRMED_IDEA_20260511_113716.md`.
- The executor understands the hard rule: no SaaS, no dashboard, no generic finance cleanup.
- Target customer is a Polish challenger FMCG, beauty, supplement, or household brand.

## Inputs
- PromoLeak idea file.
- Any notes about target categories, likely retailers, marketplaces, or distributors.
- Any existing examples of invoices, credit notes, remittances, promotion agreements, or retail-media charges.

## Instructions
1. Define the narrowest paid audit scope.
2. Specify exactly which retailer/channel is in scope.
3. Set the document period to 6-12 months.
4. List included and excluded document types.
5. Define what counts as recoverable leakage and preventable leakage.
6. State the minimum success metric for the first audit.

## Subagents
- Use one subagent to critique whether the scope is too broad or too generic.
- Use one subagent only if industry/category examples are needed.

## Output
Return a concise audit-scope memo with:
- target buyer
- channel scope
- time period
- included documents
- excluded work
- success metric
- kill signal
