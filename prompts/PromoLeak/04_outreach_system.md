# Outreach System

## Objective
Design a lightweight outreach tracking system for the first 30 target brands.

## Prerequisites
- Target list work has started or is complete.
- Outreach will be manual and targeted.
- No paid ads or automated spam campaigns will be used.

## Inputs
- Target list.
- Outreach messages if available.
- Audit scope and pilot offer.

## Instructions
1. Define CRM/spreadsheet fields.
2. Define lead statuses from identified to closed/lost.
3. Set a simple follow-up cadence.
4. Define metrics for weekly review.
5. Add fields that preserve the kill-gate evidence.

## Subagents
- Use one subagent to review whether the fields are enough to evaluate the 30-day kill gate.
- Do not use subagents for busywork if the list is already small and clean.

## Output
Return:
- CRM field list
- lead-status pipeline
- follow-up cadence
- weekly metrics
- kill-gate tracking fields
